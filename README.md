# 🌸 티타임즈 화원 - Flower Connect Hub
### 실서비스 즉시 배포 패키지 (Production-Ready Static Package)

본 패키지는 대표님의 프리미엄 네트워킹 철학과 고품격 바이럴 마케팅 엔진을 탑재한 **'티타임즈 화원 (Aurum Flora)'**의 실제 서비스용 정적 웹사이트 패키지입니다. 

서버 유지비 **0원(무료)**으로 깃허브 페이지(GitHub Pages) 또는 버셀(Vercel)에 바로 올려 실시간 고객 주문을 카카오톡 오픈채팅방으로 즉시 받아볼 수 있도록 완벽하게 설계되었습니다.

---

## 📂 패키지 파일 구성 (File Structure)

*   `index.html` : **디바이스 에이전트 라우터 (Entrance Page)**
    *   접속자의 디바이스 화면 크기 및 User-Agent를 자동으로 감지하여 PC 접속자는 `desktop.html`로, 모바일 접속자는 `mobile.html`로 1.5초의 감성적인 로딩 애니메이션과 함께 매끄럽게 포워딩합니다.
*   `desktop.html` : **PC 전용 프리미엄 매장 (Desktop Storefront)**
    *   시뮬레이터 상단 바를 걷어내고 넓은 화면을 꽉 채운 웅장하고 격조 높은 갤러리/호텔 감성의 와이드 웹사이트입니다. 3초 스마트 주문 폼, VIP 멤버십 게시판, CRM 기념일 스케줄러, 실시간 대표님 전용 통합 대시보드를 탑재했습니다.
*   `mobile.html` : **모바일 전용 프리미엄 웹앱 (Mobile Web App Storefront)**
    *   스마트폰 터치 환경에 최적화된 PWA 스타일의 전체 화면 레이아웃입니다. 하단 네비게이션 바, 터치 슬라이더, 가상 iOS 푸시 알림 배너, 모바일 전용 대표님 장부 모드를 모두 지원합니다.
*   `DESIGN.md` : 브랜드 아이덴티티 및 디자인 토큰 가이드라인 문서입니다.
*   `screen.png` : 모바일-PC 동시 구동 시뮬레이션 목업의 스크린샷 이미지입니다.

## 🛠️ 실서비스 전환을 위한 초간단 커스텀 (30초 소요)

고객이 최종 주문 완료 시, **주문 내역이 클립보드에 자동 복사**되며 대표님의 **실제 카카오톡 오픈채팅방**으로 바로 연결됩니다. 대표님의 실제 채팅방 주소를 연동하려면 아래 작업을 수행해 주세요.

1.  텍스트 에디터(VS Code, 메모장 등)로 `desktop.html`과 `mobile.html` 파일을 각각 엽니다.
2.  스크립트 영역 시작 부분(약 530라인 부근)에 정의된 아래 상수를 찾습니다.
    ```javascript
    // 카카오 오픈톡 링크 주소 설정 (실제 대표님의 오픈채팅 주소로 교체하세요!)
    const KAKAO_CHAT_URL = "https://open.kakao.com/o/sExampleChatLink"; 
    ```
3.  `"https://open.kakao.com/o/sExampleChatLink"` 부분을 **대표님의 실제 카카오톡 오픈프로필 또는 오픈채팅방 URL**로 수정하고 저장합니다.
4.  **끝났습니다!** 이제 실제 배포 후 고객이 주문 버튼을 누르면 대표님의 카카오톡으로 주문 내역서가 실시간 접수됩니다.

## 🚀 온라인 서비스 출시 및 배포 방법 (How to Deploy)

호스팅 비용을 한 푼도 내지 않고 즉시 배포하여 도메인 주소를 얻을 수 있는 두 가지 대표적인 방법을 안내합니다.

### 방법 1: 버셀 (Vercel) 배포 - 💡 강력 추천 (가장 쉬움)
1.  [Vercel 공식 홈페이지](https://vercel.com/)에 접속하여 가입 및 로그인을 합니다.
2.  Vercel 대시보드 화면에 접속합니다.
3.  본 `flower` 폴더(전체 파일이 들어있는 폴더)를 드래그하여 Vercel 대시보드의 **"Drag and Drop a folder to deploy it"** 영역에 그대로 끌어다 놓습니다.
4.  자동으로 배포 프로세스가 진행되며, 약 10초 내에 전 세계 어디서나 접속 가능한 대표님만의 무료 `https://...vercel.app` 서비스 주소가 생성됩니다.

### 방법 2: 깃허브 페이지 (GitHub Pages) 배포
1.  [GitHub](https://github.com/)에 새 리포지토리(Repository)를 만듭니다 (예: `flower-connect-hub`).
2.  본 `flower` 폴더 내부의 모든 정적 파일(`index.html`, `desktop.html`, `mobile.html`, `README.md`, `DESIGN.md`, `screen.png` 등)을 리포지토리에 업로드(Push)합니다.
3.  리포지토리 상단의 **Settings** 탭으로 이동합니다.
4.  좌측 사이드바에서 **Pages** 메뉴를 선택합니다.
5.  Build and deployment 항목의 Branch 설정을 `None`에서 `main`(또는 `master`) 브랜치로 변경한 뒤, `/root` 경로를 선택하고 **Save** 버튼을 누릅니다.
6.  1~2분 뒤 상단에 배포 성공 메시지와 함께 `https://[깃허브아이디].github.io/flower-connect-hub/` 형태의 공식 서비스 도메인 주소가 활성화됩니다.

## 💎 핵심 프리미엄 마케팅 기믹 작동 원리

*   **1:1 완벽 데이터 싱크 (`localStorage` 통합)**
    *   PC 페이지(`desktop.html`)와 모바일 페이지(`mobile.html`)는 동일한 로컬 데이터베이스를 공유하므로, 한 브라우저 내에서 테스트하거나 교차 사용하더라도 주문 기록, CRM 기념일 리스트, 쿠폰함, 바이럴 퀸 실시간 랭킹 순위가 정확하게 실시간 동기화됩니다.
*   **바이럴 리퍼럴 링크 유입 시스템**
    *   사용자가 초대 링크 복사하기를 통해 얻은 주소(`https://서비스주소/?ref=VIP_QUEEN`)로 접속하면, 시스템이 이를 자동으로 감지하여 **"15% 리퍼럴 제휴 특별 추가 할인권"**을 결제선에 자동 감액 적용합니다.
*   **오픈 톡 카피-페이스트 프로세스 (Zero-Server-Cost)**
    *   모바일/PC 고객이 예약을 확정하면 복잡한 본인인증이나 서버 결제창 연동 없이, 정교한 주문 명세표가 클립보드에 복사되고 카카오 오픈채팅창이 원클릭으로 실행됩니다. 고객은 단지 채팅방에 붙여넣기(Ctrl+V 또는 꾹 눌러 붙여넣기)를 하여 즉시 거래를 완료할 수 있습니다.
